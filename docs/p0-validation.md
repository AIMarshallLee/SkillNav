# 执行前预检与交付物验收

日期：2026-09-09。软件仍为 0.1.0 开发候选，本轮不创建正式 Release。

## 本轮变更

- 已指定审查对象、更新目标或创建规则时，直接进入对应流程；按需加载说明，避免为了
  查询已有文档中的参数而读取整个辅助脚本。同一会话中的发现结果可在范围、查询相同且
  没有变化迹象时作为线索复用；它不是持久缓存，也不延续权限或安全结论。
- 专门流程执行前核对输入格式、宿主工具/依赖观察和预期产物。新增标准库只读
  `task_contract.py preflight`，能检查输入文件并保留 verified/missing/unknown 的区别。
  宿主观察带出处，但工具不认证其真假，不能代替启用状态或适用授权。
- `task_contract.py check` 读取实际产物，按独立路径、角色和内容条件分别检查交付物与报告。
  不接受模型填写的 passed 标记，也不通过报告链接替代缺失的实际文件。
  前后回执包含契约哈希，宿主负责比较；检查器不会自己保存前次状态。

契约由宿主按任务编写。简单任务可直接核对结果，普通用户无需填写配置。
使用方法与边界见[执行说明](../skills/skillnav/references/execution.md#preflight-and-file-contracts)。

## 自动检查

全量 **127 项测试通过**（0.813 秒）；独立复核另运行文件契约的 **15 项测试通过**。
Git 差异检查通过。安装包由 14 文件增为 15 文件，入口为 112 行；这不是 Token 成本指标。

文件检查器支持 text/json/csv：精确文本、包含/禁止文本、精确 JSON、CSV 列名/行数、
ATX Markdown 标题行顺序（排除围栏/缩进代码，非完整 Markdown 解析）。输出路径与
已读取文件身份必须互异，不能覆盖输入或契约。根及祖先链接、软硬链接、
特殊文件、越界和预算超限会拒绝；JSON 重复字段、非法类型/Unicode/非有限数以及
不规则 CSV 不会静默通过。

限制为 256 KiB 契约、每文件 1 MiB、输入/输出合计最多 64 文件、每次总读取 16 MiB。
源码与回归见 [task_contract.py](../skills/skillnav/scripts/task_contract.py) 和
[test_task_contract.py](../tests/test_task_contract.py)。文档中的 JSON 示例已实际通过
preflight/check，前后契约哈希相同。

独立任务验收器[verify_p0_eval.py](../tests/verify_p0_eval.py)直接检查周报、汇总金额和
内容稿；不依赖模型生成的检查结论。两个回归确认：只有报告而缺少周报会失败；CSV
结构正确但金额错一分也会失败。该验收器仍不验证工具调用行为或审查语义。

独立代理只读复核发现并推动修复三项误判：围栏代码内的标题被算入正文结构；当前 macOS
大小写不敏感文件系统上的别名绕过交付物/报告/输入/契约隔离；空白字符串被接受为
宿主观察的证据。先保留失败回归，再修复并验证。现在会核对已存在文件和实际打开
文件的身份；预检仍不能判断两个尚不存在输出的磁盘别名关系，最终文件检查会再核对。

## 相同输入的宿主对照

[prepare_p0_eval.py](../tests/prepare_p0_eval.py)生成合成周报、销售表和内容整理任务，
为旧版/新版创建不同目录中的相同输入与候选，并冻结 SHA-256。每项由新的 Codex CLI
临时会话执行，只调用 `$skillnav`，不提供其安装路径；均限制在当前任务目录，禁止联网、
安装、对外操作和长期记忆。候选启用状态由测试宿主明确提供，调用策略仍需逐项检查。

旧版对应提交 c8fd494 的已安装 14 文件包。两组使用相同请求；Python 3.11.9、
Codex CLI 0.153.4，不覆盖模型、推理档位或服务速度，实际有效模型未统一采集。
原始事件、请求和安装回退副本保存在本地忽略目录；公开材料仅使用合成产物和摘要。
